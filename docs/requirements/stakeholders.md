# Stakeholders – Thesis Submission Portal

## 1. Student

The student is responsible for submitting and maintaining their thesis.

### Responsibilities
- Login to the portal.
- Enter thesis information.
- Upload thesis document.
- View submission status.
- Read reviewer comments.
- Submit revised thesis versions when changes are requested.

---

## 2. Faculty Guide

The faculty guide supervises the student's thesis work.

### Responsibilities
- View assigned student submissions.
- Monitor thesis progress.
- Review thesis information.
- Provide guidance or comments.

---

## 3. Reviewer

The reviewer evaluates submitted theses.

### Responsibilities
- View pending submissions.
- Open/download thesis documents.
- Provide review comments.
- Approve thesis.
- Reject thesis.
- Request modifications.

---

## 4. Administrator

The administrator manages the thesis submission system.

### Responsibilities
- Manage users.
- Manage submission deadlines.
- Monitor thesis submissions.
- View system activity.
- Access audit information.
- Manage application configuration.

---

## 5. Development / DevOps Team

Responsible for development, testing and deployment of the portal.

### Responsibilities
- Maintain Git repository.
- Review and merge changes.
- Maintain Jenkins pipelines.
- Execute automated tests.
- Build Docker images.
- Deploy application containers.
- Maintain Ansible configuration.
- Monitor application health.
- Perform rollback when required.
